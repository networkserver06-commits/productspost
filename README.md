# LEE TECH SERVICES

A static portfolio/admin landing page built for Vercel deployment.

## Local run

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy to Vercel

1. Push this project to GitHub.
2. Import the repository in Vercel.
3. Use the default static site settings.
4. Deploy.

## Notes

- The site stores admin-managed data in the browser via localStorage.
- For a fully multi-user secure admin system, migrate this to a backend/API setup.
- Update the values in `config.js` and `.env` to match your deployment preferences.
